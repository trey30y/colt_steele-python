# SKILL: generate-exercise
When the user tells you which Colt Steele chapter or Python topic they just studied:
1. Create a new `.py` file in the current directory (e.g., `01_policy_check.py`).
2. Populate it ONLY with:
   - Starter variables using a realistic company customer support, return policy enforcement, knowledge-base lookup (RAG), or order triage scenario.
   - Clear `# TODO:` comments in English describing the exact logic the user must write in VS Code.
   - `assert` statements at the bottom so the user can verify their own code by running `python <filename>.py`.
3. Stop immediately and instruct the user to open the file in VS Code and complete the `# TODO` blocks.
